# احسان AI — پروژه قابل ویرایش

وب‌اپلیکیشن فارسی راست‌چین با طراحی تیره و مدرن، گفت‌وگوی هوش مصنوعی، ارسال تصویر و فایل، گفتار به متن فارسی و خواندن پاسخ‌ها با صدای مرورگر.

## امکانات
- چت واقعی با مدل هوش مصنوعی از طریق OpenAI API
- ارسال تصویر برای تحلیل
- پیوست PDF، DOCX، TXT، MD و CSV و استخراج متن فایل‌ها
- گفتار به متن فارسی (وابسته به پشتیبانی مرورگر، معمولاً Chrome/Edge)
- خواندن پاسخ‌ها با صدای مرورگر
- رابط واکنش‌گرا برای موبایل و کامپیوتر
- معرفی احسان کیانی در بخش «درباره احسان AI»
- کدهای فرانت‌اند و بک‌اند قابل ویرایش

## راه‌اندازی روی کامپیوتر
1. Node.js نسخه 18.17 یا جدیدتر نصب کن.
2. این پوشه را استخراج کن و ترمینال را در آن باز کن.
3. اجرا کن: `npm install`
4. فایل `.env.example` را به `.env` تغییر نام بده.
5. داخل `.env` مقدار `OPENAI_API_KEY` را با کلید API خودت جایگزین کن. کلید را هرگز در کدهای داخل `public` قرار نده.
6. اجرا کن: `npm start`
7. در مرورگر برو به `http://localhost:3000`.

## فایل‌ها و ویرایش
- `server.js`: اتصال API، سرور و پردازش فایل‌ها
- `public/index.html`: ساختار صفحه و متن‌ها
- `public/style.css`: رنگ‌ها، فاصله‌ها و ظاهر سایت
- `public/app.js`: منطق چت، فایل‌ها و صدا
- `.env.example`: نمونه تنظیمات

## نکات مهم
- این پروژه برای پاسخ‌گویی واقعی به کلید API و اعتبار سرویس نیاز دارد؛ بدون آن چت کار نمی‌کند.
- کلید API محرمانه است؛ فایل `.env` را منتشر نکن.
- فایل‌های ارسالی برای پردازش به سرویس API فرستاده می‌شوند؛ فایل محرمانه ارسال نکن.
- هر فایل حداکثر ۲۰ مگابایت و هر پیام حداکثر ۵ فایل.
- صدا از امکانات مرورگر استفاده می‌کند؛ صدای فارسی به دستگاه و مرورگر وابسته است. این نسخه تماس صوتی زنده یا صدای اختصاصی تولیدشده توسط سرور ندارد.
- برای انتشار عمومی، HTTPS، محدودسازی درخواست‌ها، احراز هویت، سیاست حریم خصوصی و کنترل هزینه API اضافه کن.
- تاریخچه فعلی فقط در حافظه صفحه است و با تازه‌سازی پاک می‌شود.
